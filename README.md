# vibe-coding-final-project
This is a vibe coding final project for the JCHS coding pathway 3rd year. The challenge is to make the coolest thing possible.

## Run locally
1. Install Node.js if needed.
2. Run:

   ```bash
   node server.js
   ```

3. Open http://127.0.0.1:5500 in your browser.

You can change the listen port with `PORT=8080 node server.js`.
